# BINGO PLANET +

仿 SEGA Bingo Planet 的網頁版賓果轉盤遊戲。單一 HTML 檔案，使用 Three.js 建構 3D 物理轉盤。

線上遊玩：https://timtai1.github.io/bingo_planet/

## 玩法

- 每局開始先倒數 30 秒：只有這段時間可以按 BET 1 / BET 10 下注（可按住連押），每次押注有機率升級押注等級與觸發四大獎勵；期間也可自由按 A~D 順時針旋轉賓果卡對應的 2x2 區塊（中央十字固定不動）
- 倒數結束後開始發球（前三球每 5 秒一顆），發球後即不能下注
- 第三球入洞後轉盤中央顯示「最後旋轉BINGO只剩X秒」倒數 10 秒，之後鎖定自由旋轉
- 第四球飛行期間可按 BET 付出對應 credits 購買旋轉機會，再按 A~D 嘗試旋轉，每次成功率 10%
- 五球落定後依「押注等級 x 連線數（3/4/5 連線）」派彩，10 秒後自動開始下一局
- 支援手機直向版面：轉盤在上、Bingo 畫面在下，觸控可拖曳分隔線與操作按鈕

## 轉盤

- 26 洞：外圈 1~10、中圈 11~20、內圈 21~25、中央回收洞（落入即補發球），洞口為真實開孔
- 5、10、15、20、25 號洞為黃燈，其餘紅燈；洞環與編號貼平鍋面
- 球體物理：高速輾過洞口會撞洞緣反彈損失能量，變慢後才會翻入洞內、落底反彈坐定
- 滑鼠拖曳可調整視角、滾輪縮放，三盞聚光燈照射

## 四大獎勵（每次押注獨立擲骰）

| 獎勵 | 機率 | 效果 |
|------|------|------|
| PLUS ONE | 1/500 | 點亮中心與其上下左右其中一格（最多 5 格） |
| 4CORNER | 1/10 | 兩階段 200 / 500，四角全亮時加彩 |
| BONUS GAME | 1/10 | 兩階段：第四球入紅洞 / 黃洞則下一局免費（沿用等級） |
| ODDS UP | 1/500 | 兩階段 1UP / 2UP，押注等級直接提升 |

## 押注等級（1~10 級）

升級機率：1~2 級為 1/30，3 級以上為 1/50。各等級 3/4/5 連線賠付見遊戲右側賠率表。

## 操作

- BET 1：滑鼠點擊或空白鍵（可長按連押）；BET 10：滑鼠點擊或 Enter
- A / B / C / D：滑鼠點擊或鍵盤對應鍵，直接旋轉該區塊
- CREDITS +100：補充積分（起始 1000）
- 左右分屏與右側上下分區皆可拖曳分隔線調整大小

## 本機執行

直接用瀏覽器開啟 `index.html` 即可（需可連網載入 Three.js CDN）。
