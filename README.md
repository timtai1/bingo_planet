# BINGO PLANET +

仿 SEGA Bingo Planet 的網頁版賓果轉盤遊戲。單一 HTML 檔案，使用 Three.js 建構 3D 物理轉盤。

線上遊玩：https://timtai1.github.io/bingo_planet/

## 玩法

- 每局依序發射 5 顆球到旋轉的鍋形轉盤上，前三球每 5 秒一顆
- 第三球入洞前可按 BET 下注（可按住連押），每次押注有機率升級押注等級與觸發四大獎勵
- 第五球發射前，按住 A~D 其中一鍵再按 BET，有 1/10 機率旋轉該 2x2 區塊（順時針換位）
- 五球落定後依「押注等級 x 連線數（3/4/5 連線）」派彩，10 秒後自動開始下一局

## 轉盤

- 26 洞：外圈 1~10、中圈 11~20、內圈 21~25、中央回收洞（落入即補發球）
- 5、10、15、20、25 號洞為黃燈，其餘紅燈
- 滑鼠拖曳可調整視角、滾輪縮放，三盞聚光燈照射

## 四大獎勵（每次押注獨立擲骰）

| 獎勵 | 機率 | 效果 |
|------|------|------|
| PLUS ONE | 1/50 | 點亮賓果卡中央十字一格 |
| 4CORNER | 1/10 | 兩階段 200 / 500，四角全亮時加彩 |
| BONUS GAME | 1/10 | 兩階段：第四球入紅洞 / 黃洞則下一局免費（沿用等級） |
| ODDS UP | 1/500 | 兩階段 1UP / 2UP，押注等級直接提升 |

## 押注等級（1~10 級）

升級機率：1~2 級為 1/30，3 級以上為 1/50。各等級 3/4/5 連線賠付見遊戲右側賠率表。

## 操作

- BET：滑鼠點擊或空白鍵（可長按連押）
- A / B / C / D：滑鼠按住或鍵盤按住對應鍵
- CREDITS +1000：補充積分（起始 1000）
- 左右分屏與右側上下分區皆可拖曳分隔線調整大小

## 本機執行

直接用瀏覽器開啟 `index.html` 即可（需可連網載入 Three.js CDN）。
